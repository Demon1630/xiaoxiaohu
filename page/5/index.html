腾讯大王卡使用v2ray免流教程

腾讯虽然对于老用户可以每个月给1G通用流量，然后对于腾讯系应用可以免流40G，但如果只用腾讯王卡，1G通用流量基本上不够，这时候就可能要买1元/G的日租流量包，不划算，这里就介绍如何用vps搭建v2ray来实现免流

首先要有一台vps，因为流量需要通过走这台vps实现流量伪装

登录vps，使用脚本安装v2ray

选择1安装，然后选择3 websocket

端口必须配置为80，然后记得在vps的防火墙中放行80端口，其他默认就可以了，然后安装就可以了

等安装完成，然后输入 v2ray url ，就可以获取配置链接，进入手机的v2ray中导入就可以了

进入v2ray 中，点击导入的配置文件，在伪装域名里填入腾讯的免流域名：short.weixin.qq.com，然后在路径处填入 斜杠/

v2ray需要配置为全局模式，从而代理所有流量

其余卡混淆可以参考配置，最后自己再上网看看是否免流，避免出错

 

如果要开启热点让其他设备也使用免流流量，首先手机app上要设置允许来自局域网的连接，具体设置如图所示：

之后，到电脑上设置网络，手动设置代理，设置如图：

端口设置为手机app上的http代理端口10809，然后地址设置为你的手机热点的IP地址，可以在电脑上进入cmd>ipconfig /all查看，一般你电脑IP为192.168.1.5，则手机热点IP一般为192.168.1.1，之后电脑上的流量就可以通过手机v2ray进行免流。

如果出现断联或者网络差的问题，可以尝试到手机开发者模式中，关闭共享网络硬件加速

最后最好先尝试一下看电脑流量是否实现了免流，避免造成经济损失。

v2ray使用68端口绕过校园网wifi认证上网

原理

在我们连接到某个需要Web认证的热点后，我们已经获得了一个内网IP。在未认证时，如果我们访问HTTP网站，就会路由解析器会劫持我们的http请求然后把我们重定向到一个登录认证界面。访问HTTPS时，为响应超时。

但部分UDP的端口还是开放的，例如53、67、68、69。

因此，我们就可以把我们访问网络的流量都走开放的这几个端口，从而避免登入而实现上网

工具

首先需要有一台服务器，国内或国外的都可以，因为我们访问网络的流量都要通过这台服务器进行转发

这里我们利用68端口，首先在服务器上开启68端口，在防火墙中放行

然后在服务器上安装v2ray，可以使用2333的一键安装脚本

 

如果是国内主机，可能会出现无法连接脚本问题，因为这个脚本需要访问github，这时可以修改主机hosts文件，添加GitHub的解析

启动脚本后，选择1安装，然后选择9，伪装成微信视频流量

这里端口必须选择68，其余的默认就可以

然后回车安装即可

安装完成后就是配置客户端的v2ray，可以去官网下载带有图形界面的v2rayN：https://github.com/2dust/v2rayN/releases

下载后运行v2rayN.exe就可以，然后添加VMess服务器配置

配置参考服务器中生成的v2ray信息，也可以输入v2ray qr获取二维码直接导入

参考配置写入就可以了

然后启动v2ray，连接上校园网不用登入也可以直接访问网络，如果出现无法访问问题，可能需要改用其他端口，可以先自行测试开放的端口

阿里云上宝塔面板定时运行python脚本

小时候就想要这么个东西 然后去年双十一时候买了阿里云的学生机，感觉挺神奇，装了面板，然后我就有了我的第一个web页面。 本文介绍如何在宝塔面板中定时运行python程序（其他语言类似）

1.登陆面板 2.找到面板左侧的【计划任务】 3.在跳转的页面添加任务

  • 任务类型默认是Shell脚本，后面也有备注，还可以定时执行网站备份，数据库备份之类，这里默认就好

  • 脚本内容 python /www/wwwroot/域名/文件绝对路径

这个命令就是调用python运行某个文件，可以在远程链接中自己运行这条指令，其他的语言同理。

  • 确认各项数据无误
  • 点击确认添加任务 这样就能够定时执行某个文件啦可以各种骚操作

然后我就设计了一个爬虫的脚本，对接上了钉钉的机器人，每天自动整理数据钉钉还是好用的说

python实现百度翻译，调用js生成sign实现反爬

项目地址：百度翻译

主要通过分析百度翻译页面，查看其sign生成函数，将其调用到pyton中，从而实现反爬

需要先下载乐易助手进行js调试，下载地址：https://strivefysfxyh.lanzoui.com/ixZ0bp79nba

我们进入一个百度翻译的网址

输入一段话，然后点击翻译，右键点击检查，进入浏览器开发者模式，就可以看到浏览器发送的内容，我们点击network，然后刷新一下页面，找到v2transapi?from=zh&to=en 这个文件，从右边headers中可以看到发送的headers，发送内容等信息，我们翻译不同的内容去查看其发送内容可以发现，每次form data中不同就是query对应的翻译内容，和sign，其中sign是由MD5计算出来的，其与我们输入的翻译内容query相关，百度翻译会采用sign来进行验证，从而实现反爬虫。这里我们就需要对sign进行解密

我们点击sources，查看网页文件，找到index_e36080d.js的js文件，此时显示的内容非常乱，点击下方的格式化符号进行格式化

按住ctrl + F搜索sign ，找到sign：f（n）,这里就是js文件中生成sign的地方，下面我们还可以看到生成token的地方，我们在sign这一行左边数字处点击一下，打上断点

然后我们再次点击页面中的翻译按钮

我们可以看到，此时翻译内容已经传入，暂停到了sign函数处，我们点击右边的步进

之后我们就会进入sign的生成函数中，我们把整个function e（r）函数复制下来

加载代码，然后我们选择function e(val)函数，在下面方框中单引号中我们随便输入一个翻译单词，点击系统运行，可以看到出现错误，原因是里面的 i未定义，我们回到浏览器中的js代码中去找

可以看到，在中国e函数下面，有定义一个i变量，这个i变量主要是给前面提示错误中的u进行赋值，我们把这句话也复制到乐易编程助手中，但在后面我们在浏览器中步进js代码时可以发现，i始终被赋值成 i = 320305.131321201

添加完变量i之后，我们再点击系统运行

可以看到还报错缺少对象，我们到浏览器中定位到这个参数

它显示的是 p = S[b]未定义，但当你步进的时候，实际是p=n（p ,F）未定义，鼠标悬停在n上，可以找到这个函数对应的位置，就在 e函数上面，把这个函数也复制到乐易助手中来 此时我们再加载代码，然后运行一下

可以看到已经计算出结果了，这个结果就是对应的sign参数，所以在浏览器js代码中，我们只要复制下来n函数和e函数，然后添加一个i = 320305.131321201的初始定义，就可以完成sign的计算

将这些代码复制到python中，由于python中调用js函数需要用到第三方库PyExecJS，所以需要先安装这个库，然后调用，完成sign计算后就是对应的requests.post函数的编写，前面我们在headers中也看到了对应的form data，把它复制下来做相应的修改就可以了，完整的python代码可以到开头的GitHub中查看

使用scrcpy将手机投屏到电脑上

scrcpy就是通过adb调试的方式来将手机屏幕投到电脑上，并可以通过电脑控制您的Android设备。它可以通过USB连接，也可以通过Wifi连接（类似于隔空投屏），而且不需要任何root权限，不需要在手机里安装任何程序。scrcpy同时适用于GNU / Linux，Windows和macOS。

scrcpy是开源项目，项目地址：https://github.com/Genymobile/scrcpy

由于scrcpy只有命令行版，也可以下载一个Scrcpy-GUI的软件，通过软件界面操作，项目地址：https://github.com/Tomotoes/scrcpy-gui

 

1.手机开启adb调试

如miui系统，在 “ 我的设备->全部参数”  连续点击miui 版本  就可以开启开发者模式

开启“开发者选项”。然后在 “设置”->“更多设置”->“开发者选项” 中同时开启 USB调试 和 USB调试(安全设置)。

 

2.电脑操作

到开源地址上下载对应版本scrcpy包

然后解压出来，进入目录，输入cmd，打开命令行窗口，或者使用cmd将目录切换到文件夹中：

3.有线连接

将手机通过数据线连接到电脑，然后选择传输文件，信任电脑

在cmd中输入：scrcpy

此时就可以看到手机已经投屏到电脑上了

4.无线连接

此时已经完成了有线连接，scrcpy也可以使用无线连接：

手机和电脑需要处于同一个局域网内

先用数据线连接到手机，然后同样在文件夹中输入cmd进入命令行

输入：adb tcpip 6666

后面的6666为端口号，后面需要用到，可以自定义

然后断开USB数据线连接，在找到手机的IP地址，然后在命令行输入：adb connect 192.168.123.59:6666

192.168.123.59为手机ip地址，自行修改

显示已经连接到手机，然后同样输入：scrcpy

就可以连接上了
